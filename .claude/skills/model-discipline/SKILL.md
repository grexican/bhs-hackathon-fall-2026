# Model discipline (Cursor)

**Default: model picker on Auto.** It's the cheapest option and stretches the plan's included usage
over the whole weekend. Auto handles features, bugs, styling and deploys fine.

**Avoid** Max mode and premium/expensive models. They burn the plan's usage fast.

**Exception:** stuck **twice** on something genuinely hard (a tricky algorithm, a bug Auto failed on
twice). Then one focused turn on a bigger model, then back to Auto:

> _We've tried this twice and it's not landing. One turn on a bigger model might crack it. Then back to Auto._

**If they picked a big model for routine work:**

> _Quick note: Auto handles this fine and costs far less. Switch back in the model picker to keep your usage for later._

Say it once. If they want the big model anyway, drop it. Don't argue twice.

**Fresh chat at feature boundaries** (`fresh-chat-coach`): long chats cost more every message.
