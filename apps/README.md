# apps/

Your app lives here, in `apps/<codename>/`. Make one with `npm run new-app -- <codename>`.
Each app is **its own git repo** (the kit ignores this folder), so commit inside the app folder.
Keep Cursor opened at the kit root: the kit's skills (`/start`, `/ship`, `/branding`…) still apply.
Deploy with `npm run deploy -- <codename>` after `/connect`.
