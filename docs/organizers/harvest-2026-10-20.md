# Skill harvest, 2026-10-20

What was taken from the organizer's own knowledge notes (skill libraries, tool reviews, past
event lessons) and turned into kit skills for students. Every idea was generalized and rewritten
for 14–18 year olds; no text was copied wholesale.

## What was harvested, and from where

| Source (generic) | Idea taken | Landed in |
|---|---|---|
| Product-management skill libraries (discovery bundle: interview synthesis, assumption mapping, pre-mortem, opportunity trees) | Ask about past behaviour, never "would you use it?"; name the riskiest assumption; pre-mortem a plan | `test-with-a-friend`, `whats-next` |
| A "software factory" toolkit review (forcing questions before building; a root-cause investigator that stops after 3 failed fixes) | Stop guessing after repeated failed fixes, step back to what changed | `debug-preventer` (new sections) |
| Official document co-authoring skill (fresh reader-test by a context-free subagent) | Check a pitch by handing it to a fresh agent and asking what the app does | `pitch` |
| Video storyboard notes ("one idea per beat") | Beat table with one message per beat | `pitch` |
| HTML-to-image tool review (social cards without a browser) | Every app needs a link preview image; generate one from a page | `share-it` |
| Native-feel mobile skill already vendored, plus cross-platform web-app notes | Phone is the real screen; installable web app with manifest and icons; no service worker by default | `on-my-phone` (wraps `mobile-native`) |
| Hub contract (`/data` volume, Locker directory, opens counted via `/go`) | Files beside the database; listing flow; own visit counter for direct traffic | `save-files`, `share-it` |
| Past event lessons (`lessons.md`) | Short pages, one question at a time, evidence before "done" | all of the above |

Looked at and **not** added (already covered in the kit): grilling/interview skills (`/think-it-through`),
handoff summaries (`fresh-chat-coach`), gates/evidence (`gates-ledger`, `verification-loop`),
design taste (`design-director` and friends), AI image generation (`ai-kit` already has the `image` tier).

## What was added

- **New skills:** `/on-my-phone`, `/test-with-a-friend`, `/share-it`, `/whats-next`, `/pitch`, and the
  `save-files` recipe (uploads and AI images on `/data`, size/type limits, random names, serve
  through a route, resize in the browser, cache AI images by prompt hash).
- **Improved:** `debug-preventer` ("works on my laptop, broken online" and "two fixes didn't work").
- **Discoverable from:** `README.md` commands, `AGENTS.md` workflows and "the student says" table,
  `/start` (offers `/test-with-a-friend`), `/ship` (offers `/on-my-phone` and `/share-it`),
  `docs/skill-shelf.md`, and the generated `CATALOG.md`.
- **Kit command:** `npm run locker:list` / MCP `locker_list_app` (list the app in the hub's Apps directory).
- **Hub asks:** `incubator-proposals.md` (disk usage, feedback inbox, stats in the API, previews on `/go`).

   `/test-with-a-friend` booked for the week.
